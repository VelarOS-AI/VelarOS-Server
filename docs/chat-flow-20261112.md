# 会话交互与运行归组差量

原页面把每个模型回合当成独立回答，同一次运行会出现多个步骤汇总、复制按钮和时间。现在对照 Desktop，按 runId 将相邻的助手回合归为一条回答，保留段落、脚本及回合身份和顺序；用户、系统消息及不同运行之间不归并。每次运行保存真实状态和结束时间，共享会话组件据此渲染一个处理汇总和底部操作，不从后续消息推定运行成功。

侧栏「+」立即创建本地新会话行并选中；发送立即清空输入并显示用户消息，之后再编码附件和发起网络请求。前后端共用会话 UUID 与请求 UUID，服务端同身份回显接管本地投影，不重复建会话或消息。失败恢复当前草稿，明确手动重试复用请求身份，网络未知不会自动重放。输入上限、真实附件内容和服务端接纳边界保持原约定。

执行模式放在输入区右侧，复用模型按钮的 ghost 样式和共享菜单，选项为标准模式、完全访问、每次询问。执行程序的首行中文注释提供外层步骤说明，折叠卡无需展开即可看到当前目的。模型正文与程序回执继续分别投影，脚本状态不由汇总成功反推。

按用户明确要求去掉旧会话兼容：产品数据版本变为 2，消息时间必填，去掉旧时间缺省、全局运行状态推断和纯文本指纹分支。不加入迁移器；版本 1 数据拒绝启动。此次部署先停服务，删除旧会话、请求去重记录、通知游标和对应 Runtime 上下文，再登记版本 2。模型配置、访问令牌、浏览器登录和工作文件保留。删除是本次明确授权的部署操作，不在日常启动时自动执行。

本地一次集中验证通过格式、Server/Web 类型、HTTP/SQLite 会话接缝、即时投影与运行归组、预览收束及重启恢复、接纳原子性和网页构建。独立慢网络浏览器中创建请求延迟 2500ms，新行 220ms 可见；输入请求延迟 4000ms，用户消息 906ms 可见。脚本化模型经真实 SDK 执行两次 Node 文件写入与读取，外层显示执行说明，最后一条回答、一个复制入口，汇总 9 秒与实际执行相符，无浏览器 error。未调用付费供应商，不将本地 Windows 验证当作 Linux 沙箱验收。
